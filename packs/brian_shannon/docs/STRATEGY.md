# Brian Shannon AVWAP 确认式波段：研究规格 v1

编制日期 2026-11-01；框架基线 `3fe6153ccec5eb0598ce3dbf2e38ea0bc79ce90c`，Freqtrade 2026.9。想法键 brian_shannon；实际登记 id 必须在目标研究副本用 `lab idea add` 生成，本包未虚构已登记 id。所有新增数字都是**示例值，未经市场数据验证**。

## 方法与证据边界

**来源方观点**：先用大周期结构定位，在 AVWAP 附近观察回调及横盘，买回调后的转强而非无条件抄底；初始止损放相关低点下，较快兑现约三分之一，剩余仓位按结构管理。访谈的加密小额接急跌是单独例外，不混进本版。证据索引 B1–B4、B5–B7 见同目录 RESEARCH.md。

**模型推断**：本版选择日线 50 日均线及斜率作为大周期方向代理，以确认摆动低点作唯一锚点，小时线重新站上 AVWAP 且突破近三小时高点才参与。均线周期、摆动算法、突破窗口、分批位置均不是本人公开的完整参数。

**未知**：原交易者锚点优先级、逐笔 VWAP、实际相关低点定义、全部移动止损及实绩。OHLCV 的典型价 AVWAP 只是成交均价近似，不是全市场持仓成本。本插件不实现股票基本面、事件锚点、加密接跌例外及原版结构移动止损；继承框架止损，不能宣称完全复刻其管理。

## 市场、时序与指标

类 BrianShannonAVWAP，周期 1h；背景 1d；UTC；精确只允许 BTC/USDT:USDT 和 ETH/USDT:USDT，多头。父类日线订阅、风险、杠杆、事件、订单和止损回调保留，`framework_params={}`，不修改任何配置。框架三项 cost2x／delay1／stopslip 压力方案全部保留。

日线收盘在 SMA50 上方且 SMA50 不低于五日前，才允许。使用真实 informative 合并，未完成日线不得提前出现在小时线。数据不足或未合并方向时不开仓。

锚点候选为两小时前的 low：它严格低于左右各两根 low，才在当前小时收盘确认。不得把确认结果回填到候选时间。确认后从候选 K 线开始累加 typical_price×volume 与 volume；到确认时，这些交易都已发生，可以重算此前两根贡献，但只在确认行及之后暴露 AVWAP。下一确认低点可以重置锚点；重置本身不构成重新站上线的信号。零总成交量产生空值，不除零。

## 入场与初始失效

当前与前一行锚点必须相同；前一收盘不高于前一 AVWAP，当前收盘高于当前 AVWAP，当前 AVWAP 不低于前值；当前收盘还须高于此前三根小时 high 的最大值、close>open、volume>0。收盘以后由框架按已有配置处理下一次入场。

`fw_stop=最近六根（含信号根）low 的最小值×0.999`；`fw_entry_cap=信号 close×1.001`。两个 0.1% 均为示例缓冲。框架若按真实下单／成交价检查后距离不在既有 0.8%–3% 示例护栏内，可拒绝；不能为让信号成交扩大护栏。成交更优时父类默认 widen 可能改变绑定止损，因此不宣称止损绝不改变。

## 退出和风险

允许钩子 `take_profit_legs()` 在实际绑定风险 1R 时申请退出初始仓位三分之一（示例位置，并非本人固定目标）。剩余由 `strategy_exit()` 在最新已完成小时 close 同时跌破 AVWAP 与此前六小时 low 时请求全平，或者父类止损／最长持有／风险异常先退出。仅价格低于一条线不自动退出。

不覆盖 custom_stoploss，不模拟原版动态上移止损；这是明确的管理裁剪。分批实际成交、最小数量和重试由父类处理；回调触发不保证盘中触价即成交。1R、净 R 与杠杆收益率不同，费用、资金费及滑点仍需实测。

## 参数与验证设计

| 参数 | v1 示例 | 可预先声明的研究比较 |
|---|---|---|
| 日线方向 | SMA50 与五日斜率 | 50／100，另登记尝试 |
| 摆动确认 | 左右各 2 根小时 | 2／3；记录确认延迟 |
| 小周期恢复 | 前 3 小时 high | 3／6 |
| 相关低点 | 最近 6 小时 | 6／12 |
| 初始缓冲／追价上限 | 各 0.1% | 固定，避免本轮无限调参 |
| 分批 | 1R 退出 1/3 | 与不分批单独对照 |
| 启动历史 | 240 根小时，另备日线预热 | 工程起点，需 recursive 验证 |

一次只开放少量参数，总尝试须记录。建议先冻结开发／样本外区间，再与同样结构但不使用 AVWAP 的基线比较；不因回测效果选择最贴合历史的锚点。G0 检查不能替代 G1–G9。有限滚动历史若缺少最近锚点，重启与完整历史可能不同，应列为 G7 必测。

**证伪**：加入 AVWAP 不改善成本后结果、优势依赖事后选锚点、主要利润来自一两个难复现事件、样本外或压力测试失败，即不得声称发现有效方法。缺逐笔成交、单一交易所成交量与市场碎片化都可能改变均价。
